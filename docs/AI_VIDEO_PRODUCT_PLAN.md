# PromptFilm AI 视频生成首版方案

## 1. 方案摘要

- 产品定位：以模板驱动低门槛转化，同时提供自由提示词创作；核心路径为“看到预期效果 → 上传照片 → 一键生成 → 预览/分享 → 购买 VIP 或积分”。
- 首版包含 Templates、Create、Me 三个主入口，以及登录、模板详情、素材上传、生成进度、结果、积分/VIP、Google Play 支付和轻量管理后台。
- 首版不包含社区、公开作品流和长期作品库；源图保留 24 小时，生成结果保留 7 天。
- Android 保持单仓库组件化：`app` 负责装配，各 `feature:*` 互不依赖，通过 ARouter 跳转。
- 英文首发，所有运行时兜底消息使用英文；项目说明、注释和接口字段说明使用中文。

## 2. 产品与设计

### 2.1 设计稿范围

扩展 `design/PromptFilm.pen`，建立暗色沉浸式设计系统，并完成以下页面：

- 模板首页：余额/VIP 入口、运营 Banner、Trending、Romance、Birthday、Fantasy、Idol 等分类和模板瀑布流。
- 模板详情：视频预览、模板说明、输入槽位、预计积分和“Use template”按钮。
- 模板创作：支持“模板内置目标人物”和“用户替换目标人物”；模板声明需要一张或两张照片。
- 自由创作：模型、提示词、可选参考图、比例、时长、清晰度、灵感示例和预计积分。
- 生成进度、结果预览、下载、系统分享、重做和结果举报。
- 游客绑定 Google、VIP/积分购买、恢复购买、Me 页面和首次统一条款确认。

### 2.2 商业化体验

- 新游客获得一次标准 720p 短视频所需的可配置积分。
- VIP 提供周期积分、积分折扣、优先队列、1080p 和去水印能力；月订阅、年订阅和积分包均由后端动态配置。
- 余额不足时保留当前素材与参数并展示支付面板；购买成功后自动恢复原生成流程。
- 埋点覆盖模板曝光、详情打开、上传完成、报价、提交、成功、失败、付费墙曝光、购买和分享。

## 3. 系统实现

### 3.1 Android 客户端

- 新增 `feature:templates`、`feature:create`、`feature:generation`、`feature:profile`；保留并完善 `feature:login`、`feature:payment`。
- `core:network` 承载鉴权、错误映射和任务轮询；新增会话、媒体上传、领域模型与 Billing 基础组件。
- 客户端使用阿里云 OSS 短时凭证直传素材，不接触永久密钥；Glide 加载模板封面，播放器用于模板和结果预览。
- 使用 Play Install Referrer 获取首次渠道归因，上传原始 referrer、安装时间和签名渠道令牌；普通 `utm_source` 只用于统计，不直接授予内容权限。
- 本地只保存当前活动任务 ID、未提交草稿和提示词历史；应用重新启动后通过 `/generations/active` 恢复任务。

### 3.2 后端与数据

- 按 `auth`、`catalog`、`media`、`generation`、`wallet`、`billing`、`compliance` 领域拆分 Spring Boot 包。
- 建立用户身份、条款确认、模板、分类、输入槽位、渠道策略、上传资产、生成任务、积分钱包、积分流水、订单和订阅数据表。
- 生成任务状态固定为：

  `RESERVED → QUEUED → SUBMITTED → RUNNING → SUCCEEDED / FAILED / CANCELLED / EXPIRED`

- 创建任务时使用幂等键原子冻结积分；成功后结算，明确失败或供应商接单前取消时解冻；供应商接单后不再允许取消。
- 定时任务清理过期源图和结果，并处理超时任务、积分回退、Play 订阅对账和异常任务告警。
- 阿里模型通过 `VideoModelPort` 隔离：提交后保存供应商 `taskId`，优先处理签名回调，同时使用后台轮询兜底。
- OSS、模型凭据、Google Play 服务账号和签名密钥全部通过外部配置注入，不写入仓库。

### 3.3 对外接口

- 认证：游客登录、Google 绑定/登录、刷新会话、统一条款和年龄确认。
- 目录：模板分类、模板列表、模板详情、自由创作可选模型与参数。
- 媒体：申请 OSS 上传凭证、完成上传登记、获取短时下载地址。
- 生成：获取服务端报价、创建任务、查询任务、查询活动任务、接单前取消、举报结果。
- 钱包与支付：查询余额/流水/权益、查询商品、验证 Play 购买、恢复购买、同步订阅。
- 报价返回 `quoteId`、积分原价、VIP 价、有效期和参数摘要；创建任务必须携带未过期的 `quoteId` 与唯一 `idempotencyKey`。
- 所有公开请求和响应字段添加准确中文注释；错误返回稳定英文 `message` 和机器可读 `code`。

### 3.4 运营管理后台

- 同仓库新增 Vue 3 + TypeScript + Vite + Element Plus 管理端。
- 支持模板、分类、预览素材、人物参考素材、输入槽位、模型参数、积分价格、VIP 折扣、渠道、内容等级、排序和上下架。
- 提供生成任务查询、失败原因、积分流水、订单订阅、举报记录和全局生成/内容 kill switch。
- 后台只保存 OSS 资产标识和受控预览地址，不展示模型密钥或用户原始凭据。

## 4. 内容目录与发布约束

- 内容等级固定为 `GENERAL`、`ROMANCE`、`ADULT_EXPLICIT`，后端根据账号资格、签名渠道令牌、地区、条款版本和全局开关计算最大可见等级。
- 用户首次进入时完成年龄与真人素材使用权统一确认；输入图片、提示词和结果仍经过服务端审核，未成年人相关内容始终禁止。
- 按当前产品决策，同一个 Google Play `applicationId` 可根据签名渠道归因返回不同目录，并保留一键关闭高等级目录的服务端开关。
- 已验证风险：Google Play 当前明确禁止以性满足为目的的内容及非自愿性 sexual deepfake；渠道归因不会使同一个 Play 包脱离该政策。参见 [Google Play 不当内容政策](https://support.google.com/googleplay/android-developer/answer/9878810?hl=en)。
- `ADULT_EXPLICIT` 默认关闭，正式启用前作为独立发布门禁，需重新确认商店审核、地区规则、支付和下架风险。

- 覆盖模板上下架、渠道与等级过滤、价格变更、非法参数校验、kill switch 和受限后台权限。

- 后端全量测试。
- Android 单元测试、构建和 lint。

- `.pen` 结构与节点 ID 唯一性校验。

## 6. 已确认假设与外部前置条件

- 阿里模型采用异步 HTTP 任务；具体字段通过适配器映射，接入前需提供正式接口文档和测试凭据。
- 实际积分价格、VIP 周期赠送量和 Play Product ID 由运营配置提供，代码不硬编码生产值。
- 所有安装来源使用当前 Google Play 包名，渠道差异通过 Install Referrer 与服务端签名令牌表达。
- 素材存储使用阿里云 OSS；源图保留 24 小时，生成结果保留 7 天。
- 生成任务在供应商接单前允许取消并解冻积分，接单后继续生成并正常结算。
- 真人与成人向能力使用首次统一年龄及素材使用权确认，同时保留输入和结果审核。
- 本阶段只建设本地和测试配置，不修改生产环境、生产数据库、支付后台或 Play Console。
